# 50万元、仅沪深主板的研究股票池

配置：workflow_config_lightgbm_Alpha158_mainboard_50w.yaml

## 股票池规则

使用本地 csi300.txt 的历史成分区间，每个交易日筛选：

1. 上交所主板代码 SH600/601/603/605，深交所主板代码 SZ000/001/002/003。
   不纳入科创板、创业板、北交所及B股。
2. 当日实际收盘价大于0且不超过100元。实际价格由 $close / $factor 还原，
   不能直接把Qlib复权后的 $close 当作人民币股价。
3. 复权因子大于0、成交量大于0；缺失数据不保留。

100元上限是为减少100股交易单位对小账户配置的影响而选的研究参数，
不代表高价股更差、低价股更安全，也未做收益寻优。
这些条件以信号日收盘数据计算，不能据此假设次日仍符合条件或一定成交。

配置中的 market: csi300 是基础池，filter_pipe 才定义最终子集。
Qlib按历史日期动态筛选，训练、验证和测试都使用这套规则；
这减少了把今日名单用于全部历史带来的偏差，但不能保证源数据没有幸存者偏差。
沪深300指数 SH000300 仅作为回测比较基准。

## 资金与组合

- 初始资金500,000元。
- 目标持仓20只，目标股票仓位95%；初始约475,000元投入、25,000元预留。
- 初始每只目标资金约23,750元，不是硬性单票上限或精确等权保证。
- n_drop: 1 控制每个交易日的换出候选数；不代表每天必须换一只。
- 延用原配置费用、涨跌停近似和训练/回测区间，未按券商实际费率校准。
- Qlib的CN配置默认采用100股交易单位；复权因子缺失会影响整手模拟。

上述持仓数和仓位是可比较的实验起点，不是根据风险承受能力确定的实盘配置。

## 运行

在本目录执行：

```bash
conda activate qlib
qrun workflow_config_lightgbm_Alpha158_mainboard_50w.yaml --experiment_name personal_mainboard_50w
```

本地数据最近交易日为2026-10-23，该日筛得232只候选股。
名单和实际收盘价见 mainboard_50w_pool_20261023.csv。
这是数据快照，不是20只持仓名单或买入建议，也不要把它替换为整个历史的固定股票列表。
更新本地行情后，重新运行配置会使用新的成分与行情；CSV不会自动更新。

## 已知限制

- 本地字段没有股票名称、历史ST/退市整理标记，无法严格剔除这些股票。
  使用前需补充按日期有效的风险警示数据；只查当前名称不足以修正历史回测。
- 没有行业权重约束，20只股票仍可能集中于同一行业。
- 每日涨跌停判断沿用原模板的0.095近似；不等于精确涨跌停价或排队成交模拟。
- 实盘委托前仍需按券商可交易名单检查权限、风险警示、停牌、价格和可用资金。
- 仅做规则校验和小规模训练/回测链路检查；完整绩效、容量和回撤仍需另行评估。
